# Changelog

Each release has a section headed "## <version>". The server's "What's new" bundle and the release check read these
sections: a release needs its section here.

## 0.0.5

- The web app's API layer is generated from the server's schema; the services and models are not written by hand.
- The web app and the server share one API version (2.41).
- Shows the release notes of new versions ("What's new") once per version, once the feature is in.
