Credentials let CairnML read repositories that are not public. Each one is a GitHub App, installed on the repositories it may read. Each row shows its owner, what it is valid for, and whether it works. The private key is written once, encrypted on the server, and never shown again. An owner changes their own credentials; an admin changes the company's.
