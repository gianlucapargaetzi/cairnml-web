Track a dataset that lives on your host or behind your own storage. The dataset is versioned in a Git repository, its files are kept in DVC storage or in Git LFS, and every run records the commit it used. Local and closed datasets stay private to you and your server.

The files go to DVC storage. This is the default.

The files go into the Git LFS storage of the repository.

Fetch a dataset by its repository and commit inside a task. The folder holds the files of that commit.

Manage web datasets in the dataset registry. A registry entry does not copy the data. It names the web address of each file, a checksum, and an adapter that reads the files into the CairnML format. Entries are added through a pull request to the registry.
